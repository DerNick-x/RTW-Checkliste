# RTW Checkliste Kreis Steinfurt

Statische Webapp fuer GitHub Pages.

## Hochladen

1. Bei GitHub ein neues Repository erstellen, zum Beispiel `rtw-checkliste`.
2. Diese Dateien in das Repository hochladen. Wichtig: `index.html` muss direkt oben im Repository liegen.
3. In GitHub unter `Settings` -> `Pages` die Quelle auf `Deploy from a branch` stellen.
4. Branch `main` und Ordner `/(root)` auswaehlen und speichern.
5. Nach einigen Minuten ist die App unter `https://DEINNAME.github.io/rtw-checkliste/` erreichbar.

Auf dem iPhone die Adresse in Safari oeffnen und ueber `Teilen` -> `Zum Home-Bildschirm` als App speichern.
